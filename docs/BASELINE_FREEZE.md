# Baseline Freeze

The original authors' simulation code is preserved unchanged and serves as the
baseline for the thesis extension. In particular, `simulation/main.R`,
`simulation/fun_callback.R`, and the other original author scripts are frozen
baseline code.

Existing replication scripts, reports, results, and saved baseline outputs are
also preserved. Future thesis work must be implemented separately under
`thesis_extension/` and must not overwrite the baseline or replication record.
